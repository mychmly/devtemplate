# object：工作对象

本目录是项目工作对象的默认位置，可以放代码、文档或其他产物。模板初始只含本区域契约，不预建源码骨架、样例、清单、依赖或业务文件。

- 默认工作对象位置为本目录。已有项目可以继续使用原位置；采用其他位置时，由 Agent 将用户确认的工作对象路径（相对模板根）记录在本契约，本目录可留空，不要求搬迁或复制一份对象。
- 对象内部的格式、目录结构和技术选择由具体项目决定；本模板不代为规定，也不自动安装依赖。
- 在本目录施工仍须属于已批准并领取的任务，遵守项目允许修改的范围及对象自身已有规则。本契约不是额外授权。
- 任务、决定、交接与验证回执仍归 [任务区](../queue/AGENTS.md)；本目录放工作产物，不另建一套治理记录。
- 交付时在任务中引用实际产物及版本。不要为了记录交付而移动对象或复制大文件进任务卷。

对象位于其他位置时，遵守该处已有入口规则；本文件不赋予对外部目录的读写权限。返回 [公共入口](../AGENTS.md)。
