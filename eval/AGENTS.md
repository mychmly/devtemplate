# eval：评测方法

本区保存可复用的评测方法与比较口径，清单写在 [catalog.md](catalog.md)。评测回答“效果如何、是否改善、还有什么不足”，可面向项目产物、执行者表现或协作过程；没有实际需求时不预设评测项。

- **评测是软证据，不是准入条件。** 评分、比较与观察供用户判断，不自动放行、阻断任务，也不代替最终验收。必须满足的检查放在 [gate](../gate/AGENTS.md) 或任务验收标准中。
- 每项方法写清评测对象、所回答的问题、输入或样本、比较基线、操作步骤、指标含义和局限；不只给一个无法解释的分数。
- 需要将某项指标变成必须通过的条件时，先由用户明确确认，并按任务规则更新验收标准与批准基线；不能在看过结果后临时换口径。
- 每次评测由任务发起，记录方法版本、被评对象版本、实际输入、结果与限制。**本次读数和回执归触发它的任务卷**，本区不另存“最新结果”或任务状态。
- 调整方法时保留旧版本或可追溯依据，不覆盖旧结果，不把不同口径的分数直接当作进步。
- 主观评价、样本不足和未独立验证应明确标注。登记评测项不等于已经执行，也不授权安装工具、联网或付费。

本版仅提供 Markdown 约定，不带评测引擎或自动触发器。返回 [公共入口](../AGENTS.md)。
